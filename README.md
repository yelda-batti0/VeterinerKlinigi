## Proje Hakkında

ASP.NET Core MVC (.NET 10) ile geliştirilen bu uygulama; veteriner kliniklerinin sunduğu hizmetleri, veteriner hekimlerin uzmanlık alanlarını ve müsaitliklerini, evcil hayvanların aşı ve muayene geçmişini ve hayvan sahiplerinin randevularını yönetir. Uygulama ayrıca bir yapay zekâ asistanının kullanabileceği araçlar sunan bir MCP sunucusu içerir.

## Kullanılan Teknolojiler

- ASP.NET Core MVC (.NET 10), C#
- Entity Framework Core (Code First), SQL Server, LINQ
- ASP.NET Core Identity (rol bazlı yetkilendirme)
- Bootstrap 5, jQuery
- ModelContextProtocol.AspNetCore
